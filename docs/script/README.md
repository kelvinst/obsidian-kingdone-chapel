# Kingdone — opening script

The game script, one file per act, the way a film script is broken up. Acts 1 to
3 are written; act 4 (The Gates) is still an open outline.

[00-the-world.md](00-the-world.md) is the reference rather than a scene: what is
true of the kingdom before act 1 begins — the offices, the objects and their
laws, the stopping and the waking — written as fact so the acts can be checked
against it. Change the world there first, then the acts that show it.
